# CodingEfficiencyAHK
Some personal hotkeys to improve efficiency

This script does a few things.

1. Right Alt => Backspace. Let's you delete stuff with just your thumb, instead of having to move up to backspace.
2. Capslock => Modifier. Capslock is disabled, and now used as a modifier.
   * Capslock + EDSF => Arrow keys. Let's you navigate text without having to move off the home row
   * Capslock + WR => Word jump. Quick navigation.
   * Capslock + TG => Scroll 5 lines. Easy up/down navigation
   * Capslock + Q => beginning of line
3. Numpad => shortcuts.
   * While numlock is DISABLED, numpad numbers are now hotkeys for Win+Number. In other words, the numpad will quick launch programs on your windows bar.
   * '+' key opens program select (like alt tab)
   * '-' is play/pause (personal preference)
   * '*' is minimize
   * '/' is control+W
   * '.' is power tools launcher (ignore if you don't have it)
   * These can all be changed. It's all disabled when numlock is on.
